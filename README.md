# 神豪终端 · 随机头像图库

《神豪终端》角色卡的随机头像素材仓。角色卡按人物颜值分档，从对应档位里按确定性哈希取一张，选中后固定。

## 目录

```
assets/avatars/
  manifest.json          # 清单：分档区间 + 每张图的文件名/体积/sha256
  b1/b1-0001.webp        # 颜值 1–19
  b2/...                 # 20–49
  b3/...                 # 50–69
  b4/...                 # 70–89
  b5/...                 # 90–100
```

- 图片规格：192×192 正方形，WebP，质量 78–82，单张目标 8–14 KB，硬上限 20 KB。
- 命名：`{档位}-{四位流水号}.webp`。流水号只增不复用；已发布的文件不原地覆盖，换图发新号。
- 元数据必须清空（EXIF / PNG tEXt），避免生图提示词随图公开。

## 访问

```
https://testingcf.jsdelivr.net/gh/1208496/cj-shenghao-avatars@<commit>/assets/avatars/<档位>/<文件名>
```

主用 commit SHA 固定版本，避免缓存滞后。

> 当前这批是**测试占位图**（纯色块 + 档位编号），等正式头像生成后替换。
